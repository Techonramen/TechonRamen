# TechonRamen

**Software is the upgrade.**

TechonRamen tests free Windows and laptop software on real hardware and publishes what it actually did: the frames, the watts, the battery drain, and what got left behind after uninstalling. Every guide on [techonramen.com](https://techonramen.com) comes from a test run on one fixed laptop, with versions noted, so you can check the numbers yourself.

The focus right now is ASUS laptop software (Armoury Crate, MyASUS, G-Helper) and Windows customization with Windhawk.

## A few things the bench found

- Armoury Crate started [29 ASUS processes using about 178 MB at idle](https://techonramen.com/armoury-crate-bloatware/).
- ASUS's official uninstall tool [left a running service, 4 dead scheduled tasks and a new 78 MB process](https://techonramen.com/uninstall-armoury-crate/) after a restart.
- Capping the RTX 4070 at 2150 MHz in G-Helper [cut GPU power 23% for 4% fewer frames](https://techonramen.com/g-helper-core-clock-offset/).
- Eco GPU mode [cut idle battery drain 53%](https://techonramen.com/best-armoury-crate-settings/) compared with Standard.
- Uninstalling Windhawk the default way [leaves 67.5 MB and every mod behind](https://techonramen.com/uninstall-windhawk/).

## About

TechonRamen is run by Timothy. It started with a used Zephyrus G16 that lasted about 3 hours off the charger and a budget that couldn't cover a better laptop. Changing settings instead of hardware got it past 7 hours, and the site documents what did it. More on the [About](https://techonramen.com/about-me/) page, or get in touch through the [contact page](https://techonramen.com/contact/).
